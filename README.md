# network-learning-lab-records

Network-Laboの記事が出典とする、ラボ実験の記録とスクリプトです。

- 実験は、隔離したローカルラボ(Windows 上の VirtualBox の AlmaLinux 9 の VM)で行ったものです。
- このリポジトリは、非公開の原本リポジトリから、GitHub Actions で自動的に同期されます。直接編集しても、次の同期で上書きされます。
- 内容は、公開済みの記事が出典としてリンクしているファイルだけです。記事は、このリポジトリのコミット固定の URL にリンクします。
- `RECORDS_MANIFEST.txt` は、含まれるファイルの一覧です(記事のビルドが、リンク先の存在の確認に使います)。
- 記録は、実験時の出力の原本です(個人を特定する値や秘密情報は、公開の前に検査し、置き換えまたは除外しています)。ログやコマンド出力には、AlmaLinux、firewalld、chrony、FRR など、第三者のソフトウェアの出力が含まれます。
- 記録は実験時の状態のものです。手元の環境で同じ手順を実行する場合は、対象、影響、復旧を確認し、隔離したラボで行ってください。
